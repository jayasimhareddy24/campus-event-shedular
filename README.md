# 🎓 Campus Event Scheduler

A modern React-based campus event management and booking platform that allows students to discover campus events, reserve seats, manage bookings, and save favorite events. Administrators can create, edit, publish, pause, and manage campus events and registrations.

## 🚀 Live Demo

Add your deployed URL here:

**Live Website:** `http://localhost:5173/`

---

## 📌 Project Overview

Campus Event Scheduler is designed to simplify the management of college events.

Students can browse events, search and filter events, view event details, book seats, receive booking confirmation codes, manage their bookings, and save favorite events.

Administrators can manage events, monitor registrations, control event capacity, and view event-related analytics.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/campus-event-scheduler-pro.git
```

### 2. Open the project

```bash
cd campus-event-scheduler-pro
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the URL shown by Vite, normally:

```text
http://localhost:5173
```

## 🏗️ Production Build
